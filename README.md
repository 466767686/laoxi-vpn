# 老习VPN/习近平VPN（ProxyApp）

一个安卓网络代理客户端，内置你的 Clash 格式订阅（YAML）。

## 架构

- 界面：Kotlin + Jetpack Compose
- 代理内核：mihomo（MetaCubeX v1.19.29，随包内置 arm64-v8a / armeabi-v7a）
- 流量接管：Android VpnService 创建虚拟网卡
- 隧道：hev-socks5-tunnel（官方 sockstun 库），把网卡流量转给内核的本地 SOCKS5 端口
- DNS：隧道内建 Mapped DNS（fake-ip 模式），域名分流规则可正常工作
- 订阅：内置在 `app\src\main\assets\config.yaml`（含账号凭据，请勿外传 APK）
- 地理数据库：内置 `geoip.metadb`，GEOIP 规则无需联网下载

## 构建

```powershell
.\gradlew.bat assembleDebug
```

安装包位于 `app\build\outputs\apk\debug\app-debug.apk`。

## 安装与使用

1. 把 APK 传到手机安装（允许"未知来源应用"）
2. 打开"代理助手"，点开关，允许 VPN 权限
3. 首次连接时内核会直接解析节点域名（无需代理），随后流量全部走订阅节点

## 常见问题

- 内核启动失败：查看 App 界面上的错误信息（会显示内核日志）
- 当前仅支持 arm64-v8a / armeabi-v7a 的手机（覆盖绝大多数安卓手机）
- 配置文件中的 `mixed-port` 决定代理端口，App 会自动读取
